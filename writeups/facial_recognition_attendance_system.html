Overview

For my final-year project in my Cybersecurity degree program, I developed a real-time facial recognition attendance system (FRAS) using AI and machine learning which automates attendance logging by identifying individuals live via webcam input rather than relying on manual sign-in.

This writeup covers the system's design, key technical decisions, the testing process used to validate accuracy and inclusivity, and the documentation created to support long-term maintainability.

System Design

Main FRAS System:
  • Developed the Facial Registration System (FRS) for the main Facial Recognition Attendance System (FRAS), allowing users to register their facial profiles before accessing the attendance platform.
  • Developed a facial recognition attendance system (FRAS) using Python Programming and Machine Learning, achieving 95%+ accuracy in face detection.
  • Built using OpenCV for real-time face detection and a Convolutional Neural Network (CNN) model for facial recognition and classification.
  • Programmed backend functionality using Python programming, enabling fully automated attendance data logging to a MySQL database.

Technical Decisions & Challenges

Why did I choose CNN-based model for the FRAS?
  • Enables well-suited to image classification tasks, capable of learning distinguishing facial features like eye distance, jawline structure, and nose shape directly from pixel data.
  • Used the face_recognition library (built on dlib), which applies a pre-trained deep CNN model to generate 128-dimensional facial embeddings for each detected face.
  • Compared these embeddings using distance metrics to determine a match between a live capture and a registered face.
  • Offers stronger accuracy and better generalization across varied lighting conditions and angles, compared to simpler methods like Haar cascades.
Challenge: Due to the hardware limitations of my laptop, the FRAS camera interface experiences some lag, as the CPU lacks the processing power required for real-time facial recognition.

Testing & Validation

Tested the system across 20+ diverse facial images to validate accuracy and ensure the model performed reliably across different faces, rather than being biased toward a narrow dataset.

Result: The system achieved 95%+ accuracy in face detection across the test set, while maintaining consistent performance across a diverse range of facial images.

Lessons Learned

This project taught me that a model's theoretical accuracy doesn't always translate to smooth real-world performance even with 95%+ detection accuracy, the CNN's processing demands exposed a genuine hardware bottleneck on lower-spec machines.
