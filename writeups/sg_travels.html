Travel Booking Website

Type: Front-End Web Dev Pages: 8 Outcome: Full Wireframe & Theme Delivered
Tools:
HTML CSS JavaScript SmartDraw Coolors

Overview

Designed and planned a full travel booking website for a fictional Singapore-based travel agency as a capstone project, covering the complete process from business brief through information architecture, color theory, and detailed page-by-page wireframes built using HTML, CSS, and JavaScript.

This writeup covers the project brief, design theme, site architecture, and key page specifications from the full project documentation.

The Brief

A travel agency operating without an online presence, relying solely on walk-in customers and phone/social contact, a model that proved especially fragile during pandemic-driven travel disruption. The objective was to design a website that let customers browse and booking consultations remotely, positioning the agency as an accessible, budget-friendly alternative to larger competitors.

Goal: Enable people to travel without difficulty, with a focus on affordability - making the site a budget-conscious alternative to more expensive travel agencies.

Design Theme

Developed a 5-color palette using Coolors, built around soft, pastel tones, chosen to create a bright, approachable feel appropriate for a travel and leisure brand, while keeping the layout structured enough that visitors could find information without hunting for it.

Lessons Learned

This project reinforced the value of planning a site's full information architecture and field-level specifications before writing any code. Every page's purpose, content, and data type were defined upfront, which made the actual build far more structured than jumping straight into HTML. It also strengthened my understanding of using HTML and CSS programming language, how color theory and layout consistency shape user trust, a principle that carries over directly into building clear, usable interfaces for security tooling and dashboards.
